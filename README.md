# Expediente M.E. — Feliz cumple, Pupas Dori

Web de cumpleaños humorística para María Elena, construida con HTML, CSS y JavaScript separados y sin dependencias de build.

## Probar en local
Abre `index.html` en el navegador. Las imágenes de gatos y las fuentes externas necesitan conexión a internet.

## Publicar en GitHub Pages
1. Sube los cuatro archivos (`index.html`, `styles.css`, `script.js`, `README.md`) a la raíz del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main`, carpeta `/(root)` y guarda.
4. Espera a que finalice el despliegue.

## Personalización
Los textos están en `index.html`; los colores, tipografías y estilos en `styles.css`; las interacciones en `script.js`.
