# Feliz cumpleaños, María Elena 💗

Pequeña web estática de cumpleaños hecha con HTML, CSS y JavaScript sin frameworks, lista para GitHub Pages.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño responsive, colores, tarjetas y animaciones.
- `script.js`: botones de sorpresa, mensajes aleatorios y confeti.

## Probar localmente
Abre `index.html` en el navegador. Para que carguen las fotos de gatos y las fuentes externas, necesitas conexión a internet.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, y guarda.
5. Espera a que termine el despliegue y abre la URL que aparecerá en la sección Pages.

Las páginas publicadas en GitHub Pages son accesibles públicamente si el sitio se publica como público. Tenlo en cuenta antes de subir fotos o información personal.
